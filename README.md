# Proyecto final Landing resposiva con HTML y CSS

En este repositorio se desarrollo una pagina web estatica con los conocimientos adquiridos en el modulo 2 del curso Master en Frontend de DEVF, el cual se especializa en fundamentos del desarrollo web responsivo con CSS, utilice lo visto en las clases, en las lecturas del modulo y los recursos del notion del sensei.

# Tema 
Se desarrollo una pagina web estatica para un portafolio de presentacion, utilizando los conocimientos del modulo 1 y 2 de DevF, tomando en cuenta el diseño responsivo y el tema de flexbox.
