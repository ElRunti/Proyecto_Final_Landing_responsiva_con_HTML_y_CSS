# Aprendizajes
1. **¿Qué fue lo más fácil y lo más retador del proyecto?**
Lo mas facil fue hacer la estructura del html semantico con sus id y clases ya que tenia una idea de como estructuralo, lo mas retador fue como organizarlo visualmente por que algunas partes queria que se acomodaran diferente pero no encontraba como hacerlo.

2. **¿Qué partes de HTML semántico y Flexbox usaste y por qué?**
Use etiquetas como `header` para el encabezado, `nav` para hacer la barra de navegacion, `main` para definir el contenido principal de mi pagina,`section` para dividir mi pagina por secciones diferentes, `article` para dividir la informacion dentro  de una seccion y evitar la divitis y `footer` para hacer mi apartado final de la pagina. Del flexbox use `display: flex` para alinear el logo, enlaces y boton hamburguesa del menu,`justify-content` y `align-items` para distribuir los elementos vertical y horizontalmente y ponerlos donde queria,`flex:wrap` para que se adapte el contenido a pantallas pequeñas (hacerlo responsivo) y se acomoden en varias filas cuando el espacio se va acabando,`gap` para darle la separacion correcta a cada elemento, `flex-direction:colum` para que algunos elementos se apilen de manera vertical.

3. **¿Cómo organizaste tus media queries y breakpoints?**
Los organice en dos partes `max-width: 765px` y `max-width: 480px`, el 765 fue mas que nada por que al cortar o reducir la pantalla desde el DevTools a ese tamaño me daba ciertos problemas visuales, con 766 no pero exactamente ese pixel me daba desplazamiento horizontal y en ese punto quise que el menu hamburguesa se disparara. En cambio con 480 fue mas que nada por el tamaño de la letra, era muy pequeño y no podia leerse bien el texto y quite muy pocas partes de html que no era necesario visualizar en esa resolucion.

4. **¿Qué mejorarías en una siguiente versión?**
Agregaria funcionalidad con javascript tanto al banner de cookies y al boton hamburguesa, asi como agregar mas paginas para hacer una navegacion mas completa dentro de los proyectos.

# Limites y proximos pasos
El sitio es estatico ya que no tiene una base de datos conectada ni hace peticiones , el formulario no manda datos, no hay sombras o animaciones de las card , el meni hamburguesa no tiene una funcionalidad real.

Quisiera conectar la pagina a una base de datos real como firebase ya que es gratis para cierto almacenamiento y esta en la nube, implementar un cambio de tema claro/oscuro, añadir animaciones complejas y sombras.
